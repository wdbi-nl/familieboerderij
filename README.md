# De Familieboerderij

Gezinsapp: ouders belonen met één tik op de telefoon, het wandscherm laat het de kinderen live zien.

- App: https://wdbi-nl.github.io/familieboerderij/
- Wandscherm of tv: https://wdbi-nl.github.io/familieboerderij/#wand

Gezinsgegevens staan afgeschermd in een aparte Supabase-database; alleen gekoppelde apparaten kunnen erbij.
